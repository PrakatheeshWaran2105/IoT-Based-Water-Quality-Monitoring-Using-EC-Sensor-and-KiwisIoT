# IoT-Based-Water-Quality-Monitoring-Using-EC-Sensor-and-KiwisIoT
IoT-Based Water Quality Monitoring using NodeMCU ESP8266 and an EC (Electrical Conductivity) sensor with real-time water conductivity monitoring and data visualization through the KiwisIoT platform.
IoT-Based Water Quality Monitoring Using EC Sensor and KiwisIoT
About the Project
The IoT-Based Water Quality Monitoring System is an IoT project designed to monitor water quality by measuring its electrical conductivity (EC) in real time.

Using a NodeMCU ESP8266 microcontroller and an EC sensor, the system measures the electrical conductivity of water to help assess the concentration of dissolved ions. The collected sensor data is transmitted to the KiwisIoT platform through Wi-Fi, allowing users to remotely monitor water conductivity readings through an online dashboard.

By integrating KiwisIoT, this project demonstrates a simple and effective approach to water quality monitoring, real-time sensor data visualization, and IoT-based environmental monitoring.
